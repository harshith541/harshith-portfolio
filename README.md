# Harshith A. Shetty — Personal Portfolio

A responsive, premium-dark personal portfolio made with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract `Harshith_Portfolio_Website.zip`.
2. Open the extracted `harshith_portfolio` folder.
3. Double-click `index.html` to preview in your browser.
4. For a better local development experience, open the folder in VS Code and use the Live Server extension.

No build tools or Python packages are required. Google Fonts needs an internet connection; the website still works without it using fallback fonts.

## Included sections
- Hero and profile photo
- About and education snapshot
- Skills
- Seven project cards
- Certificate gallery with click-to-enlarge previews
- Learning journey
- Contact links to email, LinkedIn, and GitHub

## Included assets
Your uploaded portrait is saved as `assets/profile.jpg`. Uploaded certificates are in `assets/certificates/`.

## Customize
- Edit text and project descriptions in `index.html`.
- Change colors and layout in `style.css`.
- Change menu, animations, and certificate preview behavior in `script.js`.
- Replace `assets/profile.jpg` with another photo, keeping the same filename.
- Add a real project repository/demo link when you have one. Do not claim a project is deployed unless it is.

## Publish online
You can publish this static site with GitHub Pages:
1. Create a new GitHub repository (for example, `harshith-portfolio`).
2. Upload the contents of this folder to the repository root (not the ZIP itself).
3. In repository Settings → Pages, select deployment from the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to provide the public URL.

Before publishing, consider whether you want your email visible publicly. Avoid including your home address or private phone number.
